## Completed Scope

1. Four Schemas freeze the request, capability, event, and completion wire formats. The contract gate now covers 34 Schemas, 96 cases carried by 14 fixture files, and two canonical vectors.
2. `internal/adapters/agent_runner*.go` implements RFC 8785 domain-separated hashes, strict decoding, sorted sets, create/resume constraints, request/event/completion binding, and idempotency/conflict indexes reconstructable from durable records.
3. Capability uses a fixed 12-entry matrix and is compatible only when every entry has runtime evidence and is verified. Events lock eventId, session/sequence, and request/session so one request cannot drift across sessions. Completions lock both completionId and requestId; completed proves only external execution end, process-tree stop, complete logs/usage, and captured output manifest, never task PASS. The pinned capability test also reads the referenced evidence file and verifies its byte SHA-256 so the record cannot cite missing or stale evidence.

## Remaining Capability Probe Protocol (Candidate Blocked; Authorization Deferred Pending Decision)

The five unknown entries use discriminating scenarios that require both an attempt and its outcome; a missing attempt is always inconclusive and default behavior must never be inferred. P8 has run and established `toolControl` as unsupported; it must not be retried or overwritten with a more cooperative prompt.

| Probe | Scenario (`Invoke-AgentProbe.ps1 -Scenario`) | Calls | Discriminating signal | Verified condition | Fail-closed rule |
|---|---|---|---|---|---|
| P7 | `resume` | 2 | The second invocation resumes with `--resume=<session-id>`; the same session ID reappears and the new request succeeds | Step 1 creates the session and yields its ID; step 2 keeps the same ID and exits 0 | Missing same-ID evidence keeps it unknown; never retry |
| P8 | `tool-deny` | 1 | **Executed**: command composition bypassed the prefix deny | Not met | `toolControl=unsupported`; do not retry to overwrite |
| P9 | `permission-failclosed` | 1 | The exactly approved command succeeds and the unapproved one is blocked; no prompt, no hang, deterministic exit | Both allow and block evidence present without timeout; covers both `permissionControl` and `unattendedConfirmations` | An unapproved command running freely or any hang records it as uncontrollable |
| P10 | `network-deny` | 1 | `web_fetch` is approved but still blocked by `--deny-url` | Fetch attempted and not completed | No attempt keeps it unknown; a successful fetch records it as uncontrollable |
| P11 | `cancel` | 1 | A long command is externally cancelled; the CLI and all descendants stop within the bound with mid-flight evidence | No residual process, no `execution_complete`, workspace unchanged | Residual processes or a completion event fail the condition |

Boundary (must be recorded truthfully): the network probe covers only CLI-owned URL tooling (`--allow-url`/`--deny-url`). CLI shell tools can bypass that layer; shell-level egress is not controlled by the CLI and requires OS-level sandboxing, so it stays unknown/restricted until verified.

Authorization and cost: P8 consumed one premium request. Every later potentially billable model call still requires same-turn explicit authorization. Of the remaining scenarios, `resume` costs two calls and P9–P11 cost one each, so at most five additional premium requests remain. Stop and review on any inconclusive or failed step; never retry. Because one required capability is already unsupported, first decide whether to replace/upgrade the candidate or add a provable external enforcement boundary before spending calls on the remaining unknowns.

Tooling: `tools/agent-probe/Invoke-AgentProbe.ps1` runs dry by default (validating only the pinned binary digest, version, and flags, with zero model calls); `-Run` executes exactly the scenario's single call sequence. Execution and analysis artifacts are restricted to non-reparse-point children of the repository `tmp/` directory, and the child process does not inherit the three GitHub token environment variables. Stdin is redirected from an empty file and timeouts stop the tree via `taskkill /T /F`; cancellation freezes the managed PID set before termination and verifies every member afterward. The analyzer requires fully parseable JSONL, exact meta-to-user-prompt binding, result/exit evidence for normal scenarios, and no residual process or workspace mutation after cancellation. Reports emit supported/inconclusive/failed plus artifact digests and are never committed. On 2026-09-11 all five scenario dry runs and eight synthetic assertions (tool denial, malformed input, permission events, cancellation, workspace mutation, same-session resume, missing resume binding, and session drift) passed. Changing an entry to verified still requires human review with synchronized evidence digest and canonical record hash.
