## 2. 八件评估（3.2）

### 2.1 第 1 件：R-3 三选一对比

- **A 暂不可起跑**：做 = 维持现状仅登记；不做 = 不启动重评、零探针；成本 = 预算 0 / 时间 0 / 审查 0；风险 = T027-B 完成判定悬置、S-G8 保持未通过、S1 Exit 无收口时点，与 R-08/R-09「近期内能跑起来」基线相悖；回滚 = 无动作，但时间不可逆。
- **B 分阶段起跑**：做 = 按阶段 1（宽松）起跑 AT-23 重评实施片（M 档）：机制腿复用 F2-FIX 证据，真实候选腿逐次声明探针重跑 ≥3 次（启动/执行/停机）并登记 unsupported；不做 = 不引入 P′、不换候选族、不改判据；成本 = 逐次声明探针（无预设上限但逐次用户批准）+ 1 个 M 档片（约 1 片周期）+ ⑤⑥⑦（实施片触所有权/停机/身份 ⇒ ⑦ 必抽）；风险 = 固定候选仍不兼容 ⇒ 至多再得「条件闭合、不构成真实候选兼容性证明」，S-G8 不实质推进，真实端到端「通过」不可达；回滚 = 切片可回滚，探针消耗不可回滚。
- **C 引入 P′ 或换候选**：做 = 换候选族（BYOK deepseek-anthropic 或非 Copilot CLI，B1 属「未评估、未排除」）或引入 P′（B3b 装置前提）；不做 = 不维持固定候选唯一通道；成本 = 换候选 = 新候选评估片 + 探针；P′ = 装置 + 环境变更 + 「P′ 覆盖物理机目标部署环境未论证」论证义务（高）；审查单元 = 新候选片全套 + 机器纪律（多片周期）；风险 = R-08.4 禁 VM（P′ 装置涉 VM 须先裁豁免）、R-08.3 只 P 须另裁；回滚 = 候选评估可回滚，P′ 装置须 apply/revert 成对纪律。
