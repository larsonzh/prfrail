## 跨项约束
- run 所有权常驻，互斥锁不跨外部等待。
- 核心状态单写，端口不得同步反调核心。
- registry、replay、预算锁互不嵌套。
- R→重确认→launch-intent→spawn→identity。
- 停树并收敛→封存原件→intent→结算→C→closure。
- 失证保留所有权，既有终局不得改写。
- completed 只放行 step，任务仍须独立接受。
- Windows 默认 unproven，本批不升级等级。
