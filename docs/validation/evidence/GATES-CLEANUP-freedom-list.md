# GATES-CLEANUP 执行自由度清单（P24）

> 切片：`GATES-CLEANUP`。日期：2026-10-23。准则版本：v1.46。本清单登记本片在实现与回写中**实际使用**的执行自由度，逐项给出边界与理由；未列入者视为「按字面执行、无自由度」。

| 编号 | 自由度位置 | 本片取法 | 边界 | 理由 |
|---|---|---|---|---|
| F-1 | 判据 detail 的措辞 | 中文括注与英文主体并存（如 `三位 = ADR 域`、`dual-mint: other mirror unreadable, face skipped`） | 只影响 detail 文本，不改变 verdict 或触发条件 | detail 是给人读的；两种语言的括注让 CN / EN 报告都能直接引用同一句原文 |
| F-2 | DR 豁免种子集 | 取 `{1, 8, 10}`，写成显式常量 `DR_SEED_IDS` | 增删种子必须是可见 diff；不得在运行时推断 | 三个编号都已被现行语料引用但无自己的 mint 行；写成常量让「放宽主键集」成为一次可审的改动 |
| F-3 | `touched` 的边界 | 取「围栏开行 + 块内行 + 闭行」的整区间 | 只扩大「哪些块进入判定」，不改变块内三面的判定内容 | 只改开行或只改闭行的变更若不计入，等于给「重写围栏标记」留了一个不判定的空隙 |
| F-4 | 历史豁免通道的适用 | 仅对 v1.46 之前已提交、且本次变更**修改**（非新增）的报告开放；理由须非空 | 新增报告一律不得使用该通道；marker 存在时跳过声明不生效 | 该通道存在的唯一理由是「历史报告的逐字转录不可复原」；新增报告不存在这个前提 |
| F-5 | Section B 的 SEVERITY 识别 | 表格行任一单元格**整格**等于闭集值即判，另保留旧「首词」形态作并集 | 不做子串匹配、不把 `UNCOVERED` 计入 | ⑥ 实际输出把严重度放在第二格；整格相等可识别该形态，又不会把散文里提到的严重度词当成发现行 |
| F-6 | `--list` 的输出面 | 维持只列主判据 ID，不改 `--list` | 子判据仍经 `--check=G6` / `--check=G7` 选取 | 本片目标是补判据而非改入口契约；扩列会牵动既有调用方与 CI 步骤的解析 |

## 说明

- 上表六项均为**实现层面的措辞与边界选择**，没有一项放宽 §6.3 的判定对象：`G6-8` 与 `G7-f` 的触发条件、闭集与作用域都由准则正文给定，本片只选择「如何把正文写成可执行断言」。
- 本片未使用「临时降低断言强度」作为自由度：第 8 轮曾出现的弱化已在第 9 轮逐字恢复（见报告 §3 的 D4），并由 ⑦ r2 复核确认无残留。
- 本片未新增任何白名单条目（`tools/gates/cjk-newwords.txt` 与 `tools/gates/g6-whitelist.txt` 均零改动）。
