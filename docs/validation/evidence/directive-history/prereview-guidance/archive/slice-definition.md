## 变更集（本片）= 下列 D-1..D-4 ＋ 步骤 0 的 §12.4 三行

### D-1（新小节 `**4.2.1 预审员的最低核验动作（五条）**`，置于 §4.2 表后）
1. 对 diff 中提及但未展开的工件（装置脚本、测试文件、证据工件、报告附件等），必须实际读取关键文件本身，不得仅凭报告叙述或推测下结论。
2. 对 diff 或报告涉及的关键数值、时间戳、状态序列断言，必须独立复算至少 2 处：涉及原始工件时重派生；涉及跨文件引用时定位引用点核对。
3. 若发现报告或设计文档的叙述与证据工件之间存在任何矛盾（哪怕很小），必须作为独立发现列出并判定严重度——不得以「可能只是笔误」放过。
4. 反例分析须给出至少一条「若删除某个守卫 / 改回某个逻辑，哪条断言或哪份证据会失败」的可证伪判据；若无，须明确说明原因。
5. 结论必须基于审查方自己实际执行的核验；不得引用报告自身对自身的自述作为证据（自证不可信）。

附加句：以上为最低核验动作，不得以此替代自主判断；超出最低要求继续深挖亦不在此限。
