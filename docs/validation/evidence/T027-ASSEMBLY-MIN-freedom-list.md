# T027-ASSEMBLY-MIN 执行自由度清单（§1.7.3 固定路径）

> 切片 `T027-ASSEMBLY-MIN` | 日期 2026-10-03 | 清单在 ⑥ 之后、⑦ 第 1 轮之前落盘，并随三轮审查迭代更新。
> 口径：本清单只记**主控行使执行自由度**所做的实质选择与**用户直接裁定**项；判定依据 = §1.7.3「这个决定如果错了，需要修改的是什么」——错了要改代码或事实 ⇒ 自由度；错了要改契约 / 方向 / 范围 / 预算 / 授权 ⇒ 升级边界。

## 一、执行自由度（F 项）

| 编号 | 选择 | 理由 / 落点 |
| --- | --- | --- |
| F-1 | CLI 表面按「全有或全无」的八项 flags 路由到装配入口（而非只交付库入口） | 拒绝路径需要有真实生产调用者，否则构成无调用者的死代码；八项输入全是既有记录文件、零新协议。落点 `internal/console/cli.go` 的 `executeRun` |
| F-2 | 停机复核判据由「至少存在一份 pid 报告」收紧为「两份都必须存在」 | ⑦ 第 1 轮盲审报 High（部分伪造的 pid 列表可判为已停机）⇒ 采纳更强判据；两侧逐字同口径，判定顺序一致。落点 `agent_runner_postflight.go` 腿 5 与 `runtime_agent.go` 的 `managedProcessesGone` |
| F-3 | F-02 兜底采用「单入口闭包」而非逐点包裹 | 逐点包裹在新增失败路径时会被遗忘；单入口 + 源码级不变量测试使「绕过」可被机械判据抓住。落点 `ExecuteAgentRunnerRun` |
| F-4 | console 解析器改为与 adapters **逐字相同**的表达式（而非引入共享导出符号） | 本片要求最小改动且不触跨包契约域；漂移由两侧同矩阵测试与双侧变异守住。若后续判定必须共享符号，则属结构变更（错则改结构，故仍记为自由度） |
| F-5 | 变异条目 M9 / M11 / M15 标为「被取代」而非删除 | 旧锚点随整改消失是事实，删除会丢失「守卫曾经更弱」的史料；标取代并写明取代者与论证，保留可追溯性 |
| F-6 | 以源码级不变量测试（文本形态计数）承载 Windows 不可达路径的覆盖，而非引入运行时注入缝 | 平台事实是 awaiting 之后的路径在 Windows 不可达；引入 seam 会扩大生产代码面。代价是该测试可被等价改写规避 ⇒ 已登记 OB-61 候选 |
