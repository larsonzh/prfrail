## 3. 三选一裁定：**选 b —— G6-4 对 `sixstage` 围栏显式豁免（作用域子规则）**

- **判据语义影响**：G6-4 新增一条**作用域**子规则——变更新增行若落在「G7 目标报告内**已闭合**的 `sixstage` 围栏区间」，则不参与逐行扫描。四条正则、逐行扫描、白名单 split、`emit` **零改动**；豁免行不产生 finding、不产生 SKIP 记录。
- **同族先例**：OB-79 的证据树排除（冻结工件不可满足面向新文档的判据 ⇒ 用作用域排除而非白名单）、G7 的「规则条文不在扫描域 ⇒ 结构性免疫」。
- **fail-closed 设计**：① 未闭合围栏**不豁免任何行**（G7-f 已判其 FAIL，两者同红不矛盾）；② 围栏区间到**首个**裸闭栏行为止（与 G7-f 同源解析），其后行照判；③ info string 尾随空白合法（继承既有正则）；④ 豁免区间含开栏行、不含闭栏行（两行本身不可能命中四正则）；⑤ 仅 G7 目标文件集豁免，非报告文件的同形围栏**不豁免**（无 G7-f 兜底，不得开洞）。
- **可满足性**：闭合合规围栏下「一律逐字转录」100% 可达。残边 = ⑥ 原文自带裸围栏行导致结构破坏，属 G7-f 已覆盖的既有问题。
- **未选项进大改建议清单**：
  - (a) 转录归一登记位：登记文件自身含计数字面量 ⇒ 自指再豁免；逐条登记把逐字转录变为常设行政税；且需给 G6-4 新增数据通道，超出「只加作用域子规则」的边界。建议未来若出现第二种受保护逐字块再立项通用「引用豁免登记位」。
  - (c) T23 / 白名单政策修订：零预载是承重不变量（P92 实测登记即 743/744）；放开等于重开毯式豁免通道，且白名单语义是「真缺陷的逐条豁免」，与「转录属域外内容」不符。建议并入后续白名单落点评估片。
