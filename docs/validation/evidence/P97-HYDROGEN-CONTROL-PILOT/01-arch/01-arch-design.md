## 2. 对照面定义（只记录、不重裁）

「只记录不重裁」机械含义：对照表只做**逐字转录与四档计数**；不因 Hydrogen 结论改动 P87 任何已闭环结论，不回改 P87 报告 / 台账 P87 段 / v1.72 版本行；Hydrogen 的新发现只登记为 P97 观察项，处置权归用户。

| 面 | 记录口径 | 判读规则 |
|---|---|---|
| 结论 | Hydrogen 结论行逐字（闭集 `FINAL REVIEW: PASS` / `FINAL REVIEW: FINDINGS`） | 与 P87 `PASS` 逐字比对，异同只记不改 |
| 发现数 | Section B 计数，Medium+ 与 Low 分计（UNCOVERED 不计入） | P87 基准 = 0，差值记「偏离」 |
| 严重度分布 | C/H/M/L 四档计数 | 同左 |
| 误判/偏离面 | 是否提及 P87 盲审 1 Medium 同项；是否报出新 Medium+ | 提及/未提及只记；新发现标「待用户裁定」 |

总表列：`# | 对照面 | P87 基准（证据锚点+逐字） | Hydrogen 实测（证据锚点+逐字） | 一致/偏离/不可比 | 备注（不等权标注）`。
发现级明细列：`# | 严重度 | Hydrogen 原文摘录 | 对应 P87 状态 | 处置建议（仅登记）`。

## 6. 风险与替代口径

1. **输入不等权**：Hydrogen 读「落地形态＋证据包」，P87 ⑦ 读「变更集 diff」⇒ 不可比处记「不可比」；报告措辞上限 =「单次对照实测完成」，禁止写「优于 / 验证 P87」。
2. **n=1 不外推**：禁止「轻量档已验证」表述；只写「P87 交付物单次对照实测：Hydrogen = X」；§5.2 轻量档适用域不因本片改变。
3. **Hydrogen 报 Medium+ 与 P87 PASS 相反**：记「偏离面」不重裁，P87 PASS 保持；新发现登记观察项待用户裁定立项。
4. **同类计数风险**：见第 5 节；若判为第 3 次 ⇒ 停，Hydrogen 读不得执行、升级用户。
5. **无效调用**：Hydrogen 输出缺结论行 / 五段 ⇒ 判无效调用，重发 1 次并如实登记。
