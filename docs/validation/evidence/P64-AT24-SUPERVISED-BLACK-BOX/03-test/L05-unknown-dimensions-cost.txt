[6] 缺陷候选
--------
DEF-1（T028 实现缺陷候选，七项全必填未强制）
  症状：unknownDimensions = ["cost"]（其余六项全缺）或仅缺一项（如 network-access）的报告，
        经 `prfrail supervised report` 校验 exit=0 并被正常渲染；schema（Ajv）同样 ACCEPT。
  期望：按 R-09.8「七项全必填」/ 腿 5 判据「缺任何一项 ⇒ 报告不合规」应拒绝。
  根因层（两处，均需处置）：
    a) internal/chain/supervised_report.go:190 —— 只校验 non-empty + contains(cost)（单条 if，190-192）；
    b) schemas/supervised-report.schema.json —— unknownDimensions 只声明 minItems=1 + contains(cost)。
  影响面：生产链路当前不暴露该缺口（构造器在「空集」时回退到七项全集），但「部分集合」直通，
        与 R-09.8 字面不符；属「校验弱于裁定」的实现缺陷。
  修复边界：Go 层可加「必须等于封闭七项集」的校验（现有 testdata/contracts/valid 的
        supervised-report-valid 已含七项，加严不会破坏该夹具）；但若要 schema 与 Go 一致，
        需改 schemas/ + 可能补夹具 ⇒ 按 design-r1 §3 腿 5 与 3.3 属「需改 schema/fixtures ⇒ 超界停下升级」。
        ③ 不自行修复，交 ② / ⑦ / 用户裁决。
