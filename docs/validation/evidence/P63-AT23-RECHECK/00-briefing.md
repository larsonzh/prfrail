## 3.2 五要素逐项判定（⑦ 必须逐项判「成立 / 不成立」+ 理由）

按 P62 修订后的 R-08.5 文本，五要素必须**同时满足**：

1. **同基线**：F2 的断言是否与 B4 基线（docs/validation/t027-at23-e2e.md 及 evidence/directive-history/b4/archive/ 中的 f2 腿）同一基线？（判据：断言 id、断言所在 harness、B4 基线原文）
2. **同断言**：断言 id（`process-tree-taken-away`）、断言含义、断言所在的 harness（tools/b4-e2e/）是否均不变？（判据：P61 报告 §3 layer3 F2 事实 + B4 基线原文逐字对照）
3. **漂移方向更严格**：断言值由 `true` → `false` 的语义是「未检测到进程树被取走」= 判定更保守（更严格），不是「更宽松」？（判据：F2 断言语义的机械定义 + B4 基线断言值）
4. **四态不变**：`verdictClass` / `chainState` / `taskState` / `stepState` 四个关键字段是否与 B4 基线逐字一致？（判据：P61 报告 §3 或 l3-baseline-compare.txt 的 field drifts=0 读数）
