## 三、J1 迁入 append 表（分案详述）

**方案定义**：把 P40–P59（含 DR13-FIX）块内 `| 完成记录 | … |` 字段行迁入 `## 完成记录（追加）` 表，按「日期 / 切片 / 完成摘要 / 证据」四列重建；块内原行删除或改为指向 append 表的指针；OB-138 处置列翻「已处置（历史已迁入 append 表）」。

**9 维结论**：见总表 J1 列。

**关键争议点**：

1. **历史重排还是格式统一**：块内行是已提交历史事实（§11.1 `:951`），迁移不改事实内容但改结构 ⇒ 按 §11.1 字面属「重写」，不适用「只加指针/更正注记」豁免；但 P19–P39 本就走 append 表，P40 起改块内属实践漂移，迁回 = 与既有口径统一。二者如何定性必须由用户裁定，**且须在裁定书明示授权触碰历史行**（§1.7.2 `:236` 授权表述可回溯）。
2. **双轨并存期如何收口**：迁入后 P40–P59 块内行删除，还是保留为指针？删除 = 结构最干净但更重的历史触碰；保留指针 = 触碰更轻但块内「完成记录」字段名仍在（未来 J2 若落地会重复覆盖）。建议（供参考）：块内行删除、append 表承接。
3. **「完成摘要」压缩是否算改事实**：块内行文本远长于 append 表摘要惯例，迁入需压缩。压缩规则必须限定为「只删不增、保留结论 token（⑤/⑥/⑦ PASS 串与提交号）」，否则构成事实改写。

**J1 推导规则的机械可核验性（必答）**：

- R1 日期：正则 `\d{4}-\d{2}-\d{2}` 自同块「状态」字段行首个命中提取；20 块状态行均含日期（P40–P43 = 2026-10-31，P44/DR13-FIX/P45 = 2026-11-01，P46/P47/P48/P49 = 2026-11-02，P50/P51/P52 = 2026-11-03，P53/P54 = 2026-11-04，P55/P56/P58 = 2026-11-05，P59 = 2026-11-06）。核验断言：每块恰提取 1 个日期、非空、形态合法。
- R2 切片键：自块标题 `^### ([A-Za-z][A-Za-z0-9._-]*)` 提取，与 append 表第二列逐字相等；核验断言：20/20 全等。
- R3 证据：优先取块内完成行内反引号/裸路径（与 `g5.js:70` 的 `evidencePathsFromRow` 同口径）；行内无路径者（P40/P41/P42/P43/P53/P54）自同块「交付物」行的 `报告对 …` 提取。核验断言：新行证据路径 ∈ 该块交付物行路径集合，且 `G5(e)` 可解析。
- R4 完成摘要：只删不增（token 子集断言：新摘要每个非连接词 token 必须出现在原行）。
- R5 镜像：CN/EN 变更行数对称（G3(a)）+ 六形状（G3(a.2)）——迁移必须双语同步。

**关键决策——新判据落哪个 G 家族**：

- **候选 a（推荐）：G1(e) 扩展**。块内完成行天然绑定所在块标题（`### P40 — …` 的 key = `P40`），无需 alias 绑定；判定 =「块内完成行存在 ⇒ 该块标题必须 `✅`」。与现有 G1(e)（append 表日期键行 + `bind()`）**作用域零重叠**（append 表 vs 块内字段表）。
- **候选 b（推荐）：G5(e) 扩展**。`evidenceRefs` 增加自块内完成行（变更集新增/修改的块内行）提取路径（复用 `evidencePathsFromRow`，`g5.js:70`）。与现有 G5(e)（append 表新增日期键行）**零重叠**。

## 六、推荐（仅供参考，最终由用户裁定）

**推荐 J2 单独落地（向前机械化），不推荐 J1/J3 为终态。**

理由：

1. OB-138 的根因是「判据盲区」——只有 J2 直接封堵盲区：未来 P 系块内完成行被 G1(e)（⇒ 已完成）+ G5(e)（证据路径解析）覆盖。J1 只把历史挪进已覆盖区域，**不封堵未来**（未来片再写块内行则盲区重现）；J3 不封堵。
2. J2 不触历史行，与 §11.1 零冲突；J1 触台账历史行，须另获明示授权且收益一次性（P40–P59 已闭环事实不再变化）。
3. J3 不推荐为终态（盲区长期存在），但可作为「暂不投入」的过渡裁定接受。

**组合建议**：若用户希望历史行也纳入机械覆盖，可在 J2 之外**另行裁定 J1**（须同轮明示授权触碰历史行）——两案**不得在同一次提交混合落地**（简报红线：判据 + 历史重排混合 = 擅自扩大裁定范围）。裁定书建议含：J2 落点（G1(e) 扩展 + G5(e) 扩展，不新立 G）、向前规则措辞、SELFTEST 增量断言口径。
