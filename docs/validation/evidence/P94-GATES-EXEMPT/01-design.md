## 2. 三件合并评估

### (a) `GATES-EXEMPT` 本体 —— 做（重定边界为「同构扩展」，不做标记机制）

- 原始意图追溯：P33 ①-3 原始形态 (i) 是「报告 §1 异常登记区的 `gate-exempt` 注释式标记区间，使 G2 / G6-4 / G4b 在区内跳过」。v1.55 已落 ①-3(ii) 记录态豁免句（§1 异常登记区触发判据属记录态义务、由 ⑤ / ⑦ 人工核验）——**§1 自撰文本面已闭合**；P93 通道 b 闭合了「`sixstage` 围栏触发 G6-4」面。
- 剩余缺口真实存在且是第二类受保护逐字块：**`sixstage` 围栏体触发 G2（被禁串）与 G4b（语料外汉字）**——§11.3 与 v1.76 新句规定围栏体为审查方逐字转录、主控**不得为满足其它判据而改写**，而 P93 只豁免了 G6-4。
- 裁定：**不做 `gate-exempt` 标记机制**（对主控自撰文本开机械豁免洞等于判据架空；嵌套 / 空区间 / 非报告文件的 fail-closed 复杂度不成比例），**做同构扩展**——把「已闭合 + 五段按序的 `sixstage` 围栏体」作用域豁免从 G6-4 复制到 G2 / G4b。标记形态问题因此消解：不引入任何新标记，唯一豁免载体 = 既有围栏结构（G7-f 已兜底其结构面），落点限 G7 目标报告的闭合围栏。

### (b) P93 移交 (a) 通用引用豁免登记位 —— 不做

- 依据：§11.3 的逐字转录义务**仅**落在 `sixstage` 围栏（⑥ 最终消息）；报告其余位置的审查方原话转引是主控自撰总结，**可措辞改写**（P93 A-4 先例），无「不得改写」义务 ⇒ 缺口不真实存在。
- 次要理由：逐条登记 = 常设行政税；登记文件自身含计数字面量 ⇒ 自指再豁免，且与 T23 零预载承重不变量冲突。
- 未来最小形态（记录备用，本片不落地）：**必须独立文件**（如 `tools/gates/quote-exempt.txt`，绝不并入 `g6-whitelist.txt`），条目 = 报告路径 + 行区间 + 理由；自指天然免（落在 `tools/gates/` 扫描域外）；单独设零预载断言。触发条件 = 未来新增围栏之外的逐字转录义务。

### (c) 白名单登记门槛与断言政策 —— 做（只加条款，不放行）

- `g6-whitelist.txt` **保持零条目，T23 三断言逐字不动**（零预载承重不变量不变）。
- 落地 = 准则 §6.3「两条白名单」段 + `g6-whitelist.txt` 注释头追加**登记门槛条款**（纯条文，不触判定逻辑）：登记充要条件 ① 用户同轮显式裁定（§1.7.4 四要素）或 ⑦ 终审背书；② 豁免对象 = 「规则过粗误伤的合法行」，真缺陷须修文本不得登记；③ 三字段必填且理由含上下文摘录；④ **先改断言再登记**为同轮原子动作——把 T23 的零预载断言改为「预载 == 显式批准清单」断言，登记与断言变更同一提交且 ⑨ 全绿；⑤ 报告 §1 与 §12.4 留痕。该设计在**不放弃零预载**的前提下表达「登记必须显式且可审计」（任何未来登记必然留下可见的断言变更）。
- 与 P27 裁定的区分：`cjk-newwords.txt` = G4b 合法新词常设登记（语义即增长），`g6-whitelist.txt` = 真缺陷逐条豁免（语义即零预载）——两文件分工写入条文，禁止混用。

## 3. 通道落点设计

- **文件 / 函数**：`g2.js` 的 `run` 在行循环头部插入「行号 ∈ 豁免集 ⇒ continue」；`g4b.js` 的 `run` 在 `newC` 收集处按 `ctx.addedLineNumbers(f)` + `ctx.readLineArray(f)` 逐行剔除豁免行字符（豁免集为 null 时走原快路径，输出逐字节不变）。
- **剔除集合**：两文件各自约十余行结构判定循环（与 P93 的 `sixstageStructurallyValid` 同构），正则与序列常量**单源自 `G7.internals`**（`sixstageBlocks` / `targets` / `SIXSTAGE_SECTION_RE` / `SIXSTAGE_SECTION_SEQ`），无本地正则定义；豁免行号集合与 P93 的 `sixstageExemptSet` 同形。判定谓词（G2 四正则与自指防护、G4b 差集与白名单与缓存 fail-open、G6-4 四正则与 split 与 `emit`）**全部零改动**——豁免发生在扫描前，属候选集合剔除。
- **fail-closed 面**：① 未闭合围栏不豁免任何行；② 五段不齐或乱序不豁免；③ 仅 G7 目标文件豁免，非报告同形围栏不豁免；④ 区间 = `[start, end)`，闭栏行本身不可能命中；⑤ 提前闭合 / 嵌套由 G7 解析器处理；⑥ 标题行 `.trim()` 与 G7-f 同口径；⑦ 豁免行不计入 G2 的 preexisting INFO。
- **报告方式**：G2 / G4b 的 detail 仅在豁免发生时附加 `fence-exempt N`（同 G6-4 口径）；无豁免输入时输出逐字不变。
- **缓存**：G4b 缓存键含 `runBody()` 源码摘要 ⇒ 本片改动自动失效旧缓存，`CACHE_VERSION` 不升。
- **`g6-whitelist.txt` 注释头**：追加「作用域豁免（证据树 / `sixstage` 围栏，含 G2、G4b、G6-4 三判据）不是白名单职责 + 登记门槛条款指引」，条目保持零。
