# 任务包 / 阶段结项报告模板（SLICE-CLOSEOUT-TEMPLATE）

> 用法：任务包 / 阶段收尾时按本模板撰写结项报告（触发锚点见第 4 节，T027 结束为**首例**）；**回看由主控撰写**，**前瞻由主控起草待决问题清单、业务方向由用户裁决**（依 `docs/DELIVERY_DIRECTIVE.md` 的 §1.7.3 与 §3.2）。本模板是结构母版，不含规则实体；与准则冲突时以准则为准。

## 1. 结项对象

本报告覆盖的目标：`<task-package-id>`（任务包）与 `<阶段>`（阶段标识），再给切片范围、时间范围与前提（一句话）。

## 2. 回看（主控撰写）

只汇总可核验事实（取自各切片报告与台账，不凭记忆），分四小节。

### 2.1 做了什么

已完成的切片 / 里程碑逐项，附报告路径或提交号。

### 2.2 完成与未完成

完成项勾选式列出；未完成项逐条写原因。

### 2.3 未完成汇总

跨切片汇总未完成项与根因，使跨切片遗漏可见。

### 2.4 审查与门禁

汇总各片审查结论与门禁读数，只引用报告、不重跑。

## 3. 前瞻（主控起草 + 用户裁决）

分两小节：待决问题清单（主控起草）与裁决记录（用户裁决）。**业务方向不得由主控独断**（依 §1.7.3 与 §3.2）。

### 3.1 待决问题清单（主控起草）

按「问题 / 候选方案 / 建议（可选）/ 待谁裁决」逐项列出。

### 3.2 用户裁决记录

逐项记「问题 / 用户裁决 / 日期 / 落点（OB / ADR / 立项切片）」。

## 4. 锚点与回写

注明触发锚点（**T027 结束（首例）** / S1 结束 / S2 结束 / …）与回写去向（`REMAINING_SLICES{,_EN}`、`DEV_PLAN{,_EN}`、OB / ADR）。
