## 八、跨片协作纪律（要点）

| 要素 | 内容 |
|---|---|
| 载体表 | ①⑤⑥⑦ 只读；②③⑧ 可写；禁止 `prfrail-tester` 跑审查层；批量辅助必须 `deep-reasoner` |
| 派单串行 | `runSubagent` 串行阻塞，禁止并行；每次传 `agentName` 与 `model` |
| 提交信息语言 | 一律英文，格式 `<type>: <summary>`；含非 ASCII 时用 `git commit -F` |
| 临时件 | 一律 `tmp/<切片ID>/`，只由 ⑧c 清理本片目录 |
| 门禁执行 | 中间环节 `--all --skip-base`；提交前全绿；纪律 E：先精确 `git add` 再跑 `--scope=index` |
| 围栏 | 按路径排序、TAB 分隔、CN 与 `_EN` 逐字节相同 |
| 事实 vs 判断 | 可独立核对的产出错误不构成作废；判断类必须重做 |

本版新增纪律候选（均由 P47 的 G6-4 误杀实证）：
1. 台账与报告禁写「标识后紧跟量词」的形态：该量词会被 G6-4 读作行数字面量，应写「该条目」或「该记录」。
2. 报告不得逐字引用触发判据的字符串：自述判红原因时复现同一字面量会再次判红，应用描述性措辞替代。
