11. **线性化点纪律**：涉及持久化状态机时「持久化成功」必须是线性化点，内存 CAS 只作同进程快速拒绝缓存。

13. **审查方归档纪律**：⑤⑥⑦ 产出必须逐字原文归档（`04-reviews/`）；主控不得按要点重建。
14. **装配验证片纪律**：断言必须落在可证伪的机械判据上；常量恒等须显式声明非哨兵；报告必须声明生产代码是否零改动。
15. **评估类切片 ⑨ 后必停 ⑩**：评估类无实现对象，⑨ 全绿后停在 ⑩ 等同一轮授权。
16. **单次输出不得超过 10,000 字符**：超限前分批；禁止自重启；按需读取。
17. **压缩即结片**：上下文到 100K 或出现压缩提示 ⇒ 立即结束当前片，一会话只跑一个 L 档切片。
18. **起跑消息必须含「文档同步更新」章节**：若切片改变了项目阶段状态或契约能力，⑧ 阶段须同步更新权威文档；漏写即视为结构缺陷。

### 门禁坑（P48 六条 + P49 七条 + P52 两条 + P55 四条 + P56 一条 + P57 零条 + P58 一条）

> P48 起至 P55 起的条目沿用 v45，P56 条目沿用 v46，P57 无新增；**v48 新增第 21 条（来自 P58）**。

20. **子代理自删前必须先报主控**（候选纪律，P56 实证）：执行角色在 `tmp/<切片ID>/` 之外误建临时目录后**立刻自删**，致 §5.1 自愈档的「读数②基线」不可得。正确次序：**自报 → 主控取预快照（`tmp` 递归计数 + `git status --porcelain -uall`）→ 自删 → 零残留回读**；违者按非自愈档处置。
21. **PowerShell 直读 UTF-8 stdout 会按 GBK 解码**（P58 实证）：`Select-String` / `Out-File -Encoding utf8` 处理门禁与 `gh` 的中文输出后成乱码，既产生假阴性（扫描结果恒为 0），也会造成二次转码（改落盘的文件复读仍是乱码）。正确做法：用 `node -e` 的 `execFileSync(cmd, args, {encoding:'utf8'})` 直读、`fs.writeFileSync` 原样落盘，或让脚本只输出 ASCII 摘要（非 ASCII 逐字符掩码为 `#`）。
