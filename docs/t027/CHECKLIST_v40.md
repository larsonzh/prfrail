| **纪律 U · 禁逐字引用触发串** | 报告不得逐字引用触发判据的字符串：自述判红原因时复现同一字面量会再次判红，须用描述性措辞替代 |
| **纪律 V · 大任务拆分与半截防污染** | 大任务必须拆分为小步串行派发，单次载荷尽量减少；超时报错时必须用 `git status`/`git diff` 检查半截产物；若有半截且变红必须取证并精确 `git checkout` 回退，严禁盲目重试（P50 实证：② 全量派单连续 5 次网络超时且两次留下半截产物，拆分 ②a–d 后全程绿灯） |

### 门禁坑（P48 六条 + P49 七条，供后续复用）

### P48 起（沿用）

1. **`tmp/` 下的 `.go` 副本会被 `go build ./...` 编译**：审查输入包中的源码副本一律用 `*.go.txt`，否则 `base go build/vet/test` 三腿判红。
2. **`G7-b` 围栏处置词闭集**：未入库临时件写 `local-only`，写 `local` 会报 unknown disposition。
3. **报告出现 `INDEPENDENT SCAN` 标记必须配 `sixstage` 围栏**：围栏内用 `## Section A` 至 `## Section E` 各一次，结论行只保留块内最后一个非空行，并在围栏外披露合并差异。
4. **写 `.md` 必须显式补 BOM**：用 node 回写时漏传 BOM 参数会立刻触发 `G4a`（P48 踩两次）。
5. **`G8-b` 要求 MANIFEST 逐件列出载荷**：列目录行会被判「payload not listed」。
6. **读数必须最后回填**：收档会改变 `changed=` 计数与 `scanned=` 读数，报告落笔前重测一次。

### P49 起（新增）

7. **改 `.github/workflows/*.yml` 必须同步 `internal/release` 工作流冻结契约**：`workflow_test.go` 的 `expectedScripts` 逐字锁定每个脚本步骤体的 SHA-256；① 类影响面检索必须覆盖该契约（P49 的 ① 漏查导致 r1 后契约族红，r2 同步后闭环）。
8. **远程 SSH 预检**：非交互会话不加载用户 PATH（`source ~/.bashrc` 常被早退保护吞掉），必须 `bash -lc` 并探查 `~/.local/bin` 等用户级目录（P49 因此漏查 VM 既有 go1.27.1，已按偏差登记）。
9. **PowerShell → ssh 嵌套引号**：多层引号与 `$(...)` 会被 PowerShell 先行解析；跨壳复杂命令一律写远端 shell 脚本上传执行。
10. **⑥ 输出必须 A–E 形状**：`Section A`（范围）→ `Section B`（发现或 `(no findings)`）→ `Section C`（证据）→ `Section D`（可证伪性审计）→ `Section E`（无法验证部分 + 推翻条件）→ 块末结论行；格式偏离按 §7.2 允许重发一次，重发计入预算。
11. **围栏与磁盘枚举必须一致**：新增任何载荷后须同轮补报告围栏行 + MANIFEST 条目 + 重算 SHA256SUMS（P49 漏补 ⑥ r2 围栏行触发 G5(d)）。
12. **`gofmt -l .` 会扫进隐藏目录**：`.vscode/scripts/` 下的一次性 `.go` 也会被 `base gofmt` 列出（`./...` 通配虽忽略点目录，gofmt 直走不忽略）；放临时 Go 工具前先 `gofmt -w`。
13. **重算哈希用只读脚本**：编辑器占用某载荷文件时写式归一化会 `EBUSY`；只读重算 + 仅写 `SHA256SUMS.txt` 可绕开。
