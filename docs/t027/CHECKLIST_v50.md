### 门禁坑（P48 六条 + P49 七条 + P52 两条 + P55 四条 + P56 一条 + P57 零条 + P58 一条 + P59 一条 + P60 一条）

> P48 起至 P55 起的条目沿用 v45，P56 条目沿用 v46，P57 无新增；**v49 新增第 22 条（来自 P59）**；**v50 新增第 23 / 24 条（第 23 条来自 v49 D 口径小修实证；第 24 条来自 P60）**。

20. **子代理自删前必须先报主控**（候选纪律，P56 实证）：执行角色在 `tmp/<切片ID>/` 之外误建临时目录后**立刻自删**，致 §5.1 自愈档的「读数②基线」不可得。正确次序：**自报 → 主控取预快照（`tmp` 递归计数 + `git status --porcelain -uall`）→ 自删 → 零残留回读**；违者按非自愈档处置。
21. **PowerShell 直读 UTF-8 stdout 会按 GBK 解码**（P58 实证）：`Select-String` / `Out-File -Encoding utf8` 处理门禁与 `gh` 的中文输出后成乱码，既产生假阴性（扫描结果恒为 0），也会造成二次转码。正确做法：用 `node -e` 的 `execFileSync(cmd, args, {encoding:'utf8'})` 直读、`fs.writeFileSync` 原样落盘，或让脚本只输出 ASCII 摘要。
22. **审查方结论行取值必须严格属于 §4.1 闭集**（P59 实证）：⑦ 首轮输出 `FINAL REVIEW: CHANGES_REQUESTED`，取值表外 ⇒ 按 §7.2 格式偏离处置；同 stage 重发**计入额度上限**（首轮占 1 次终审），不得写「无效轮次不占额度」。主控派单文本应把合法取值枚举写进任务包。
23. **归一脚本对已 BOM 文件需先剥后加**（v49 D 口径小修实证）：`readFileSync(f,'utf8')` 保留前导 U+FEFF，写回时再拼 `\uFEFF` 即成双重 BOM（G4a 报 `bom=2`）。正确写法：先循环剥尽全部前导 BOM，再重加单 BOM；落盘后核 BOM=1 / 双 BOM=0 / CR=0。
24. **G6-4 把「版本号后紧跟『行』」的组合误判为行计数断言**（P60 实证）：`\d{2,}\s*行` 只查「数字后紧跟『行』」；版本号后跟「行」的组合会被判红。安全改写：把「行」换成「条目」类措辞（数字与「行」之间插字即安全）。
