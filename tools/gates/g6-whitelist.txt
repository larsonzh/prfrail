# G6 whitelist (DELIVERY_DIRECTIVE section 6.3, G6 台账元数据一致性).
# A hit exempts ONE finding; the criterion is reported PASS when every finding is
# either absent or registered here.
# Format (TAB separated, all three fields mandatory):
#     <match><TAB><file><TAB><reason / context excerpt>
#   match  substring of the offending line (the smallest text that identifies it)
#   file   repository-relative path the entry applies to ('*' = any file)
#   reason the registration reason PLUS the context excerpt that justifies it
# A malformed entry (missing field, empty reason) is a usage error: the runner exits 2.
# Entries are reviewed by ⑤/⑦ like any other claim. Do not register a real defect.
#
# Scope exemptions are NOT whitelist duties. Two regions are excluded by the criteria
# themselves, so they never need (and must never get) an entry here:
#   1. the evidence tree `docs/validation/evidence/**` (OB-79);
#   2. a CLOSED `sixstage` transcript fence of a validation report - G6-4 scope
#      sub-rule, v1.76 (P93): the fence body is a verbatim ⑤/⑥/⑦ transcript that the
#      controller must not rewrite.
# Registering a transcript line here does not exempt anything: a preloaded entry fails
# SELFTEST (T23), because the empty file is a load-bearing invariant.
# Since v1.77 (P94 GATES-EXEMPT) those two scope exemptions cover G2, G4b and G6-4
# alike, and they stay NOT whitelist duties: each criterion drops the exempt lines
# before scanning, so no entry here can widen or narrow them.
#
# Registration threshold (a real hit only; the file stays empty otherwise):
#   (a) an explicit same-turn user ruling (section 1.7.4, four elements) or a (7)
#       final-review endorsement;
#   (b) the registered line must be a LEGITIMATE line wrongly caught by too-coarse a
#       rule - a real defect must be fixed, not registered;
#   (c) all three fields present, and the reason carries a context excerpt;
#   (d) the matching SELFTEST preload assertion must change in the SAME commit
#       (registration and assertion change are one atomic action) and the (9) gate
#       run on that same commit must be all green;
#   (e) the report section 1 and section 12.4 record it.
#
# Division of labour - do not mix the two registries:
#   tools/gates/cjk-newwords.txt = standing registration of legitimate NEW characters
#       (its semantics is growth);
#   tools/gates/g6-whitelist.txt = a per-hit exemption of a line a too-coarse rule
#       wrongly caught (its semantics is an EMPTY file) - never merge the two.
#
